# tegaki

**tegaki（日语「手書き」/ てがき）＝ 手写。手写数字识别，一个 HTML 页面，模型在你浏览器里跑。**

在画板上写一个 0–9 的数字，松手就出结果——不是只给一个数字，而是把十档概率一起摊开给你看。

> 「手書き」＝ 手（て）＋ 書き（かき，書く 的名词形），字面就是「用手写出来的字」。
> 日语里填表时常写「手書きで記入」，是「手写」这件事最日常的说法，跟「印刷」相对。
> 取这个名字就是图它短、直白，而且和工具的用途完全对得上。

## 它和常见的 MNIST 网页 demo 有什么不一样

大部分 demo 是「把整块画布缩到 28×28 直接喂模型」，数字写小一点、写偏一点就废了。这里换了个预处理：

1. **裁到墨迹包围盒**——只取真正写过的区域；
2. **等比缩进 20×20**——和 MNIST 训练集里数字占的位置对上；
3. **按质心居中到 28×28**——不是按外框居中，是按笔画的重量分布居中。

实测同一笔「写在右下角的小号 7」：整块缩放的做法猜成 **6（0.80）**，裁切 + 质心居中猜成 **7（1.00）**。

其它：

- **边写边猜**：画的过程中每 120ms 出一次结果，抬笔再定稿；
- **十档概率条**：能看到模型在犹豫什么，而不是只丢一个数字；
- **按笔画撤销**，不是只能一键全清；
- **画板按 devicePixelRatio 放大**，笔迹不糊；
- **tfjs 钉死 4.22.0**，不用 `@latest`（哪天 CDN 一升级就可能崩）；
- 推理全在本地，画的东西不出浏览器。

## 跑起来

纯静态，不需要构建。但因为要 `fetch` 模型文件，得用 HTTP 起，不能直接双击打开：

```bash
cd tegaki
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

## 结构

```
index.html        页面与样式（无框架、无构建）
app.js            画板、预处理、推理、渲染
model/model.json  TF.js GraphModel（CNN，MNIST）
favicon.svg
```

## 模型

- 输入 `[1, 28, 28, 1]`，输出 `[1, 10]`（0–9 的概率；若不是概率会自动做一次 softmax）
- 卷积网络，在 Colab 上从零训练，再经 SavedModel 转成 TF.js GraphModel
- 权重一共 148 KB，首次加载后浏览器会缓存

## 部署

GitHub Pages，直接吃仓库根目录。自定义域名的话，在仓库 Settings → Pages 填上，
再让域名的 CNAME 指向 `<用户名>.github.io`。
